Molecular learning · Undergraduate Thesis

EGNN for RTP
Property Prediction

Can explicit molecular geometry improve prediction of excited-state properties relevant to room-temperature phosphorescence?

I implemented a 3D graph pipeline and an equivariant model, then compared it with a SMILES Transformer using a shared data split.
