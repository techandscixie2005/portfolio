The teaching problem

A fluent answer is not enough to show that a learner understands quantum physics. Sources, calculations, and the learner’s own reasoning need to remain visible. I built QuantumAgent to connect these elements in a staged teaching workflow.

What I built

01 / Teaching

A staged learning workflow

Initial attempts lead into diagnosis, guided work, teach-back, transfer, and independent problem solving. Backend stage rules constrain progression.

02 / Evidence

Traceable course retrieval

Retrieved passages retain source, page, and version information so an answer can be checked against course material.

03 / Computation

Generated code with checks

A pipeline applies AST checks, isolated execution, and independent numerical validation for the finite rectangular barrier case.

04 / Continuity

Recoverable learning records

Attempts, evidence, calculation results, and workflow snapshots persist so a learning session can be resumed.

How the system fits together

The React/TypeScript workbench connects to the Python/FastAPI/LangGraph backend. PostgreSQL holds the authoritative records; pgvector and Neo4j support derived retrieval indexes, with Redis for temporary coordination and caching. Scientific tools include NumPy, SciPy, and SymPy.

Scope & Limitations

This completed competition prototype is demonstrated through a finite rectangular barrier case with test-driven inputs. The recording does not validate arbitrary quantum problems, a full course, or long-term learning outcomes. Operation depends on external services and a configured execution environment; no maintained public live service is promised.
