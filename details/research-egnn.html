Prediction of Room-Temperature Phosphorescence Molecular Properties Based on Equivariant Graph Neural Networks

Supervisor: Prof. Jun Jiang
Fall 2025 - Spring 2026
Graduate Project

Overview

This thesis focuses on predicting key excited-state properties of organic room-temperature phosphorescence (RTP) candidate molecules using equivariant graph neural networks (EGNNs). RTP is a photophysical phenomenon with applications in organic electronics, bioimaging, information security, and sensing.

The modeling scope is isolated-molecule property prediction: singlet-triplet energy gap, spin-orbit coupling strengths, and S1 oscillator strength. It does not directly predict final solid-state device performance, experimental quantum yield, or phosphorescence lifetime.

Dataset

The thesis uses a dataset of about 6,000 organic RTP candidate molecules with quantum-chemistry labels:

  • Singlet-triplet energy gap ΔE(S1-T1)
  • Spin-orbit coupling SOC(T1→S1)
  • Spin-orbit coupling SOC(T1→S0)
  • S1 oscillator strength fosc,S1
  • Molecular structures with optimized geometries

Model Architecture

We implemented an 8-layer EGNN_Sparse_Network with SE(3)-equivariant message passing, which preserves rotational symmetry throughout the network:

  • Node Features (21-dim): Atom type, hybridization state, aromaticity, valence electrons, etc.
  • Edge Features (6-dim): Bond type, bond length, distance in molecular graph
  • Message Passing: Equivariant updates using molecular topology, edge attributes, and 3D coordinates
  • Output: Scalar properties predicted through invariant aggregation

Training Strategy

  • Geometric Data Augmentation: Random rotations and translations of molecular coordinates
  • Regularization: Layer-wise Dropout with a gradually increasing rate
  • Learning Rate Schedule: ReduceLROnPlateau scheduling
  • Baseline: Character-level SMILES Transformer trained on the same molecules
  • Train/Val/Test Split: 4,800 / 1,050 / 150 molecules with a fixed split shared by EGNN and Transformer

Key Insights

  • Explicit 3D geometry and equivariant inductive bias improved prediction over the sequence baseline across all four targets
  • SOC(T1→S0) was predicted most accurately, while SOC(T1→S1) remained the most challenging target
  • Results support using 3D molecular graphs for RTP-related excited-state property screening at the isolated-molecule level
  • The conclusions should not be interpreted as direct predictions of solid-state RTP performance, quantum yield, or lifetime
