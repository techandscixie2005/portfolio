MultiSpec-GeoDiff: Geometry-Constrained Multimodal Spectra-to-Structure Retrieval

2025 – 2026
Research Demo / Prototype
GitHub Repo

Problem

Inferring molecular structure from spectroscopic evidence is a fundamental inverse problem in chemistry. Given multimodal spectra (IR, Raman, NMR, MS), how do we recover plausible geometry-consistent molecular structures? This is the spectra-to-structure retrieval problem: encode spectra, retrieve candidate structures, and rank them by geometric plausibility.

Traditional approaches treat each spectrum independently or rely on fragment-based library search. This project explores whether coordinate-aware multimodal encoders and geometry-constrained retrieval can narrow the structure candidate space more effectively.

Core Idea

The central hypothesis is that spectral features carry implicit geometric information about molecular structure — bond lengths, angles, and connectivity patterns leave signatures across multiple spectroscopic modalities. By jointly encoding multiple spectra with explicit coordinate bias and using attention across modalities, we can produce a geometry-informed molecular representation for retrieval, even before running a full geometric generative model.

  • Coordinate-aware spectral encoding: Spectral inputs are processed with positional encodings that reflect 3D structural priors, biasing attention toward geometrically meaningful spectral regions.
  • Intra-modal attention with spectral coordinate bias: Within each modality, attention weights are modulated by estimated inter-atomic distance signatures embedded in the spectral domain.
  • Cross-modal fusion: Multi-head cross-attention combines IR, Raman, NMR, and MS representations into a unified molecular embedding.
  • Retrieval and reranking: Candidate structures are retrieved from a molecular database and reranked using forward physical validation (comparing predicted spectra against input).

Implemented Demo / Prototype

This is a research demo and prototype, not a production-ready model. The current implementation includes:

  • A coordinate-aware spectral encoder that processes IR and Raman inputs with distance-bias attention
  • Intra-modal attention layers with spectral coordinate bias for each modality
  • Cross-modal fusion module combining IR and Raman representations
  • A retrieval pipeline that ranks candidate molecules from a pre-indexed structural database
  • Forward physical validation: candidates are scored by comparing DFT-computed spectra against query spectra

The prototype demonstrates the feasibility of the coordinate-aware multimodal approach but does not yet include the full geometric generative component. See the GitHub repository for implementation details and example notebooks.

Technical Path

  • Stage 1 – Spectral Encoding: Each spectral modality (IR, Raman, NMR, MS) is processed by a dedicated encoder. Coordinate bias is injected via learned positional encodings derived from estimated inter-atomic distance distributions.
  • Stage 2 – Intra-modal Attention: Self-attention within each modality, with attention weights modulated by spectral coordinate bias to emphasize geometrically informative spectral regions (e.g., fingerprint region in IR).
  • Stage 3 – Cross-modal Fusion: Multi-head cross-attention across modalities produces a joint molecular representation that integrates complementary structural information from each spectrum type.
  • Stage 4 – Retrieval: The joint embedding is used to query a molecular structure database. Top-k candidates are retrieved via embedding similarity.
  • Stage 5 – Reranking: Candidates are reranked through forward physical validation: DFT-computed spectra are compared against the query spectra, and candidates with the best match are returned.
  • Future Extension – Geometric Generation: A planned GeoDiff-style generative module would propose novel structures conditioned on the joint spectral embedding, moving beyond retrieval into de novo structure generation.

Current Scope

  • Multimodal encoding supports IR, Raman, NMR, and MS spectra
  • Coordinate-aware attention mechanisms are implemented for IR and Raman modalities
  • Cross-modal fusion produces joint molecular embeddings
  • Retrieval pipeline with forward physical validation reranking is functional
  • The geometric generative extension (GeoDiff-style) is designed but not yet implemented
  • Current evaluation is on curated small-molecule datasets

Limitations

  • This is a research prototype; retrieval accuracy on large and diverse molecular databases has not been systematically benchmarked.
  • The coordinate bias mechanism relies on estimated distance distributions, which may degrade for highly flexible or conformationally complex molecules.
  • Forward physical validation uses DFT-computed spectra, which introduces computational cost and DFT-approximation error into the reranking step.
  • The geometric generative extension is in design phase; the current system retrieves from an existing database rather than generating novel structures.
  • Training data requirements for effective cross-modal fusion across all four modalities have not been fully characterized.

Next Steps

  • Implement the GeoDiff-style geometric generative module for de novo structure proposal conditioned on spectral embeddings
  • Benchmark retrieval and reranking performance on standard spectra-to-structure datasets
  • Extend coordinate-aware encoding to handle conformational flexibility through multi-conformer spectral averaging
  • Explore self-supervised pretraining strategies for the spectral encoder to reduce dependence on labeled structure data
  • Investigate uncertainty quantification for retrieval confidence and candidate ranking thresholds
